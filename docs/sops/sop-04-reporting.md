# SOP-04: Reporting

## Overview
Reports go out weekly to stakeholders: spend, ROAS by campaign, pacing
status, fatigued creatives, and audience winners.

## Numbers discipline
Every figure in a report comes from a real query run — never hand-typed.
ROAS is revenue over spend with a 50 dollar average order value unless
stated otherwise. Pacing uses day 14 of 30 as the reference point in
this demo dataset.

## Anomaly notes
Any campaign flagged overspending or underspending gets a one-line
cause note: delivery block, creative fatigue, or budget cap. Unexplained
spikes are escalated to T2 for operator review, never silently smoothed.

## Delivery
Reports are delivered as chat summaries in this demo. In production the
same payload feeds the dashboard table and the weekly PDF.
